# kinoeve

Веб-сервис для выбора фильма на вечер. Первая версия — фронтенд на Svelte 5 и TypeScript с локальным набором данных и интерфейсом для подключения бэкенда.

Приложение находится в [`frontend/`](frontend/README.md). В нём есть каталог, страница фильма, уточнение подборки, темы и настроения, сохранение и отметка просмотренного.

## Локальный запуск

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

Node.js 22.14+ и pnpm 11.25.0. Прототип: `http://127.0.0.1:5173/`.

## Docker

```sh
docker compose up --build -d
```

Команда запускается из корня репозитория. Прототип: `http://localhost:8080/`, на сервере — `http://IP-СЕРВЕРА:8080/`. Порт опубликован на всех сетевых интерфейсах. Чтобы изменить его, скопируйте `.env.example` в `.env` и задайте `FRONTEND_PORT`.

Проверка: `docker compose ps` и `curl http://localhost:8080/health`. Остановка: `docker compose down`. После перезагрузки сервера контейнер запускается автоматически.

По умолчанию используется локальный набор фильмов. Для подключения бэкенда задайте `DATA_SOURCE=http` и `BACKEND_UPSTREAM` в `.env`. Подробности запуска, проверки и ограничения — в [инструкции фронтенда](frontend/README.md); будущие ручки бэка — в [контракте API](frontend/API.md).
