# kinoeve — веб-прототип

Svelte 5, TypeScript, Vite. Две страницы: каталог `/` и фильм `/movies/:id`. Роутер на History API поддерживает прямые ссылки, Back/Forward и возврат к подборке с прежними параметрами. «На потом» — состояние каталога `/?saved=1`.

## Запуск

Node.js 22.14+ и pnpm 11.25.0:

```sh
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

Открыть `http://127.0.0.1:5173/`. Проверки и production-сборка:

```sh
pnpm check
pnpm test
pnpm build
pnpm preview
```

## Docker

Из этой папки:

```sh
docker compose up --build -d
```

Открыть `http://localhost:8080/`. Многоэтапная сборка: Node собирает статические файлы, nginx обслуживает приложение на 8080 от пользователя `nginx`. Healthcheck: `/health`. Для прямых ссылок на фильмы настроен SPA fallback. Контейнер не требует Node в runtime.

Прототип развёрнут через корневой `compose.yaml` на http://31.76.17.185:8080/. Docker-сборка выполняет проверки типов, тесты и production-сборку; после запуска проверяется `/health`.

## Что работает

- Стартовые 3 фильма, расширение до 6 и 9 с сохранением предыдущих вариантов. После 9 предлагается уточнение.
- Тема или настроение в заголовке и прокручиваемой модалке; альтернативное направление — в нижней карусели с градиентами и стрелками только там, где можно листать.
- «Больше юмора», динамика, анимация и другие уточнения меняют подборку и возвращают к трём вариантам. Всегда показаны пять тегов; ранее выбранные возвращаются по мере ротации.
- Сохранение и «уже смотрел» общие для каталога и страницы фильма; хранятся в localStorage. Список переживает перезагрузку.
- У всех 29 фильмов есть аннотация, оценки из исходного набора, трейлер, кадры, создатели и блок «Что отмечают в отзывах» со ссылками на рецензии. Тезисы ведут к фильмам с похожими характеристиками. Награды показываются при наличии сведений. Длинный сюжет раскрывается по нажатию.
- Состояния загрузки, ошибка с повтором, неизвестная страница/фильм и пустой список сохранённого.

## Данные

`src/data/movies.json` — неизменённый JSON из `movies-data.zip`: 10 фильмов, дата сбора `24092026`. Постеры из архива находятся в `public/assets/posters/`.

`src/data/prototype.json` — 19 фильмов из нашей предыдущей подборки. Идентификаторы дополнений имеют префикс `proto-`, чтобы не смешивать их с ID Кинопоиска. Их оценки перенесены из прототипа и не являются актуальной выгрузкой.

`src/data/movie-details.json` — дополнения для всех 29 фильмов, проверенные 12 октября 2026: аннотации дополнений, жанры и страны, создатели, 132 фотографии людей, 78 кадров, трейлеры и короткие тезисы рецензий. Награды популярных фильмов дополнены по фильмографиям. Редакционные тезисы пересказывают мнения из указанных источников, не являются цитатами или статистикой согласия зрителей. В интерфейсе доступны рецензии и раскрываемые источники материалов.

`src/lib/api/data.ts` нормализует исходные записи и накладывает дополнения по ID. Архив пользователя сохранён неизменным. У людей без доступной фотографии остаются инициалы; сведения о наградах и площадках не выдумываются. Отзывные характеристики участвуют в локальном поиске.

19 трейлеров используют прямое видео в HTML-плеере, 8 — встроенный YouTube, 2 — переход на страницу источника («Седьмая печать» и «Изгнание»). Видео не копируются в репозиторий, поэтому воспроизведение зависит от доступности внешних сервисов и сети пользователя. Рядом с встроенным плеером всегда есть ссылка на источник; ошибка прямого видео также переключает действие на эту ссылку. Кадры и портреты оптимизированы и хранятся локально в `public/assets/details/`, поэтому страницы не зависят от загрузки сторонних изображений.

Происхождение новых изображений и видео сохранено в `src/data/detail-sources.json`: локальный файл, исходный URL и страница источника. Основные источники — Rotten Tomatoes, сайты правообладателей, КиноТВ, Киноафиша и Beat Film Festival; сведения и награды сверены по фильмографиям. Старые постеры описаны в `src/data/sources*.json`, ранее добавленные материалы — в `public/assets/film-detail/*sources.json` и `photo-credits.json`.

Локальный подбор — детерминированная демонстрация: тема, настроение, пожелания, совпадения слов и редакционный порядок из прототипа. Это не ML и не полноценное понимание естественного языка. Если точных совпадений мало, добавляются близкие фильмы с пояснением. Подробности контрактов — [API.md](API.md).

## Подключение будущего бэка

Компоненты обращаются только к интерфейсу `MoviesApi`, а не к JSON напрямую. Две реализации: локальная `mock.ts` и HTTP `http.ts`. HTTP-режим не подменяет ошибки локальными рекомендациями.

Для разработки скопировать `.env.example` в `.env.local`, установить `VITE_DATA_SOURCE=http`; `VITE_API_BASE_URL=/api`. Vite проксирует `/api` на `API_PROXY_TARGET` (по умолчанию `http://127.0.0.1:8000`). Перезапустить dev-сервер.

Для Docker режим задаётся при запуске, без пересборки образа:

```sh
DATA_SOURCE=http BACKEND_UPSTREAM=http://backend:8000 docker compose up -d
```

Контейнер `backend` должен быть доступен из сети compose и обслуживать `/api/*`. Значение `BACKEND_UPSTREAM` — origin без пути и завершающего `/`; nginx сохраняет исходный `/api/...`. Если бэк находится снаружи Docker, указать доступный контейнеру адрес. `localhost` внутри контейнера обозначает сам фронтенд.

Для прямых запросов на отдельный домен установить `API_BASE_URL=https://api.example.org/api`; на бэке потребуется CORS. Runtime-конфигурация отдаётся в `/config.json` с `Cache-Control: no-store`. Секреты в конфигурацию фронтенда не помещать.

Авторизация, серверные пользовательские списки, реальный рекомендательный алгоритм и данные площадок просмотра — следующий этап.

## Состояние выбора

Каталог использует Svelte stores. Тема или настроение, последнее действие уточнения, использованные подсказки и раскрытие 3 → 6 → 9 сохраняются при переходах «Сегодня» / «На потом» и при возврате со страницы фильма. URL воспроизводит состояние; кнопки браузера «Назад» / «Вперёд» восстанавливают предыдущую итерацию. `sessionStorage` сохраняет выбор после обновления вкладки; если хранилище недоступно, работает память приложения. Результаты последних 20 запросов остаются в памяти, поэтому возврат и расширение не пересобирают выдачу.

Выбранное настроение поднимается в заголовок, а темы переходят в нижнюю карусель. Выбор темы возвращает исходную композицию. Каждое уточнение пересобирает тройку и заменяет предыдущее пожелание. Всегда показаны пять тегов: скрыто только текущее уточнение, остальные упорядочены по возрастанию числа нажатий. При равных счётчиках сохраняется редакционный порядок. Ранее выбранные теги возвращаются, поэтому варианты не заканчиваются.

Счётчики находятся в отдельном Svelte store и сохраняются в `localStorage` текущего браузера. Смена темы, переходы между страницами и обновление вкладки их не сбрасывают. Навигация назад или восстановление URL не считаются нажатием. Если хранилище недоступно, счётчики остаются в памяти до перезагрузки.
